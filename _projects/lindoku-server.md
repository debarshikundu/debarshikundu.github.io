## What it is

The server component for **Lindoku**, a Sudoku app. It handles the backend side of the game, keeping puzzle logic and client code separate.

## What I learned

This was an early lesson in drawing a boundary between a client and a server: what belongs on the device, what belongs in the backend, and how much of the game state the server should actually trust.
